# Security policy

Please report security problems privately, not in a public issue:
use **Security → Report a vulnerability** on this repository (GitHub private vulnerability reporting).

Include the page or route, steps to reproduce and the impact. Do not include real private editor links or client links.
We aim to acknowledge reports within a few days and ask for reasonable time to fix before public disclosure.

Out of scope: denial-of-service or load testing, social engineering, and findings that need a victim's private editor link.
